# 3Delicias
Nombre del equipo: 3Delicias

Autores: Enzo Marin y Juan Morillas Cordani 

Contexto: Una pastelería que utiliza impresoras 3D para crear postres 
y decoraciones personalizadas con ingredientes comestibles, combinando 
tecnología y arte repostero.

Objetivo: Ofrecer postres innovadores y personalizados mediante
impresión 3D, uniendo creatividad, sabor y tecnología para transformar 
la experiencia dulce.
